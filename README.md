# E-PowerRTK: ប្រព័ន្ធគ្រប់គ្រងការប្រើប្រាស់ភ្លើង និងចេញវិក្កយបត្រ (Electricity Billing & Management System)

ប្រព័ន្ធគ្រប់គ្រងការប្រើប្រាស់អគ្គិសនី បង្កើតឡើងដោយប្រើប្រាស់ **Python (Flask)** និង **SQLite3** អមដោយទម្រង់វិក្កយបត្រផ្លូវការដែលបំពាក់នូវ **KHQR Code** សម្រាប់ទូទាត់ប្រាក់តាមប្រព័ន្ធបាគង (Bakong) ឬធនាគារក្នុងប្រទេសកម្ពុជា។

---

## 🚀 របៀបដំណើរការប្រព័ន្ធ (How to Run)

### វិធីទី១៖ ដំណើរការតាមរយៈ Batch File (ងាយស្រួលបំផុតលើ Windows)
ចុច Double-click លើឯកសារ `run.bat`។ ប្រព័ន្ធនឹងបើក Web Server លើ `http://127.0.0.1:5000` និងបើក Browser ដោយស្វ័យប្រវត្តិ។

### វិធីទី២៖ ដំណើរការតាមរយៈ Terminal / PowerShell
```powershell
# 1. ចូលទៅកាន់ Folder គម្រោង
cd c:\Users\pea\Desktop\E-PowerRTK

# 2. ដំឡើង Flask (ប្រសិនបើមិនទាន់មាន)
py -m pip install -r requirements.txt

# 3. ដំណើរការកម្មវិធី
py app.py
```
បន្ទាប់មកបើក Browser ទៅកាន់អាសយដ្ឋាន៖ `http://127.0.0.1:5000`

## 🗄️ រចនាសម្ព័ន្ធទិន្នន័យ (Database Structure - ៣ តារាងគោល)

ប្រព័ន្ធនេះត្រូវបានរៀបចំឡើងយ៉ាងមានរបៀបរៀបរយដោយប្រើ SQLite (`electricity.db`) ជាមួយនឹងតារាងទាំង ៣៖

### ១. តារាងអតិថិជន (Customers)
| ឈ្មោះ Field | ប្រភេទ (Type) | ការពិពណ៌នា |
| :--- | :--- | :--- |
| `customer_id` | TEXT (PK) | លេខកូដសម្គាល់អតិថិជន (ឧទាហរណ៍៖ `CUST-001`) |
| `name` | TEXT | ឈ្មោះពេញរបស់អតិថិជន |
| `phone` | TEXT | លេខទូរសព្ទទំនាក់ទំនង |
| `address` | TEXT | អាសយដ្ឋាន / ទីតាំងផ្ទះ |
| `meter_number` | TEXT (Unique) | លេខសម្គាល់នាឡិកាស្ទង់/កុងទ័រ (Meter ID) |
| `registered_date` | TEXT | កាលបរិច្ឆេទចុះឈ្មោះ (YYYY-MM-DD) |

### ២. តារាងកត់ត្រាការប្រើប្រាស់ (Meter Readings)
| ឈ្មោះ Field | ប្រភេទ (Type) | ការពិពណ៌នា |
| :--- | :--- | :--- |
| `reading_id` | TEXT (PK) | លេខកូដកត់ត្រា (ឧទាហរណ៍៖ `READ-202609-001`) |
| `customer_id` | TEXT (FK) | ភ្ជាប់ទៅកាន់តារាង Customers |
| `month_year` | TEXT | ខែ/ឆ្នាំ (ឧទាហរណ៍៖ `09/2026`) |
| `old_reading` | REAL | លេខកុងទ័រចាស់ (kWh) |
| `new_reading` | REAL | លេខកុងទ័រថ្មី (kWh) |
| `total_units` | REAL | ថាមពលប្រើប្រាស់សរុប = `new_reading - old_reading` |
| `recorded_date` | TEXT | កាលបរិច្ឆេទទទួលបានការកត់ត្រា |

### ៣. តារាងវិក្កយបត្រ និងការទូទាត់ (Invoices & Payments)
| ឈ្មោះ Field | ប្រភេទ (Type) | ការពិពណ៌នា |
| :--- | :--- | :--- |
| `invoice_id` | TEXT (PK) | លេខសម្គាល់វិក្កយបត្រ (ឧទាហរណ៍៖ `INV-2026-001`) |
| `reading_id` | TEXT (FK) | ភ្ជាប់ទៅកាន់តារាង Meter Readings |
| `rate_per_unit` | REAL | តម្លៃក្នុង ១ kWh (លំនាំដើម៖ ៨០០ រៀល/kWh) |
| `total_amount` | REAL | ចំនួនទឹកប្រាក់សរុប = `total_units * rate_per_unit` |
| `due_date` | TEXT | ថ្ងៃផុតកំណត់បង់ប្រាក់ |
| `status` | TEXT | ស្ថានភាពទូទាត់ (`Paid` ឬ `Unpaid`) |
| `created_at` | TEXT | កាលបរិច្ឆេទបង្កើតវិក្កយបត្រ |

## 📐 រូបមន្តគណនា (Formulas)

1. **គណនាគីឡូភ្លើងប្រើប្រាស់:**
   $$\text{ថាមពលប្រើប្រាស់ (kWh)} = \text{លេខកុងទ័រថ្មី} - \text{លេខកុងទ័រចាស់}$$
2. **គណនាទឹកប្រាក់សរុប:**
   $$\text{ទឹកប្រាក់ត្រូវបង់ (រៀល)} = \text{ថាមពលប្រើប្រាស់ (kWh)} \times \text{តម្លៃក្នុង ១ kWh (៨០០ ៛)}$$

## ✨ លក្ខណៈពិសេសចម្បងៗ (Key Features)

- **Smart Auto-fill:** នៅពេលជ្រើសរើសអតិថិជនដើម្បីកត់ត្រាភ្លើង ប្រព័ន្ធនឹងទាញយកលេខថ្មីចុងក្រោយរបស់អតិថិជននោះមកដាក់ជា "លេខចាស់" ដោយស្វ័យប្រវត្តិ។
- **Live Calculation:** បង្ហាញការគណនាចំនួន kWh និងទឹកប្រាក់រំពឹងទុកភ្លាមៗនៅពេលបញ្ចូលលេខកុងទ័រថ្មី។
- **Cambodian Utility Bill Design:** ទម្រង់វិក្កយបត្រស្តង់ដារ A4 មានភាសាខ្មែរយ៉ាងច្បាស់លាស់។
- **KHQR Payment Ready:** បង្ហាញ QR Code សម្រាប់ស្កេនទូទាត់ប្រាក់ ស្របតាមទម្រង់ Bakong KHQR។
- **Print / PDF Ready:** ចុចប៊ូតុង "បោះពុម្ព ឬ រក្សាទុកជា PDF" នឹងរៀបចំទម្រង់បោះពុម្ពយ៉ាងស្អាតដោយមិនមានប៊ូតុង ឬ Navigation រំខានឡើយ។
- **One-click Status Toggle:** អាចចុចលើ Badge ស្ថានភាព (បង់រួច / មិនទាន់បង់) ដើម្បីផ្លាស់ប្តូរស្ថានភាពបានភ្លាមៗ។
